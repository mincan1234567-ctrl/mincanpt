# 민찬피티 (MINCANPT) — 최종 준비본

민찬피티 AI 창작 플랫폼의 프론트엔드 준비본입니다.

## 포함된 기능
- 민찬피티 로고/브랜드 UI
- 사용자가 지정한 메인 배경 이미지
- PC / 태블릿 / 모바일 반응형
- 새 대화 및 대화 목록
- 웹사이트 만들기
- 사진 만들기
- 영상 만들기
- PPT 만들기
- 동영상 편집
- 사진 편집
- 마인크래프트 모드 만들기
- 물건 고장 분석
- 제작자 메뉴
- 관리자 모드 UI
- 오늘 사용자 수 / 전체 사용자 수 자리
- 기능별 전체 ON/OFF
- 전체 공지 / 공지 내리기
- 사용자 관리 메뉴
- 사이트 상태 메뉴
- **크레딧 시스템 없음**
- **사용자별 제한 없음**

## GitHub 업로드
저장소 루트에 `index.html`, `style.css`, `script.js`, `README.md`가 있어야 합니다.
`assets/mincanpt-background.png`도 반드시 함께 올려주세요.

## 중요
이 파일은 프론트엔드 준비본입니다. 실제 로그인, 소셜 로그인, 사용자 수, 관리자 인증, AI 생성 API 등은 안전한 서버/DB/API 연결이 필요합니다.
제작자 인증번호나 비밀번호를 JavaScript에 직접 넣지 마세요.
